# v0.0.1 acceptance checklist

Use this checklist for scope lock, PR tracking, and release review.

- [ ] Wheel builds
- [ ] Wheel installs in clean venv
- [ ] `scieqlint` console script works
- [ ] `python -m scieqlint` works
- [ ] `py.typed` included
- [ ] CLI commands exist
- [ ] CI skeleton is green
- [ ] Contributor files exist

Deferred scope must be listed explicitly in release notes.
