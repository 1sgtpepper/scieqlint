# v1.0.0 release checklist

Use this checklist for contract readiness, PR tracking, and final release review.

## Implemented fixture coverage

- [x] Suppressed diagnostics are hidden from default JSON golden output.

- [x] Packaged `mechanics` preset behavior is covered by a release fixture.
