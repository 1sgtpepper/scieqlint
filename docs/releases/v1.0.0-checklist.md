# v1.0.0 release checklist

Use this checklist for contract readiness, PR tracking, and final release review.

The v1.0.0 pack-check wrapper ran `python -m compileall src` followed by
`python -m pytest`. The checked-off wrapper reference below records that release
history; the wrapper is no longer present in the current tree.

## Implemented fixture coverage

- [x] Suppressed diagnostics are hidden from default JSON golden output.
- [x] Suppressed diagnostics can be included in JSON golden output when configured.
- [x] Packaged `mechanics` preset behavior is covered by a release fixture.
- [x] Alias normalization behavior is covered by a release fixture.
- [x] Config, CLI, JSON Schema, and reporter golden checks run through
      `python scripts/check_pack.py`.

## Completed release scope

- [x] Graph export data model and schema.
- [x] Explicit symbol directives and undefined-symbol diagnostics.
- [x] Project mode, deterministic file ordering, and diagnostic baselines.
- [x] Stabilization checks.
- [x] Stable CLI, JSON, SARIF, config, and public API contract readiness checks.

Deferred scope must be listed explicitly in release notes before tagging v1.0.0.
