# Contributor Guide

Welcome. SciEqLint is built for narrow, exact, well-tested contributions.

Start with:

1. `README.md`
2. `SPEC.md`
3. `GOOD_FIRST_ISSUES.md`
4. `CONTRIBUTING.md`
5. this docs section

A good SciEqLint PR changes one layer, includes tests, names non-goals, and preserves deterministic output.
