# Support

Use GitHub Issues for reproducible bugs, docs gaps, and scoped feature requests.

Before opening an issue:

- check `README.md`, `docs/limitations.md`, and `docs/diagnostics.md`,
- search existing issues,
- prepare a small Markdown/MyST example when reporting analysis behavior.

SciEqLint does not provide mathematical proof services, broad CAS support, notebook execution support, or private consulting through the public issue tracker.

For vulnerabilities, follow `SECURITY.md` instead of opening a public issue.
